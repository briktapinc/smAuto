Text generation

Script and topic writer. Edit live prompts on the Prompts tab.

OpenAI API spends chat tokens on scripts and topic batches. LM Studio uses the local OpenAI-compatible server (no OpenAI cloud). ChatGPT and Claude write natively through Desktop MCP (save_script, create_topic) — unless the writer is LM Studio, in which case they should call generate_script_via_api.

Optional: when text_provider is chatgpt/claude, scheduled jobs can draft a tagged script via OpenAI or LM Studio. Agent can still override with save_script. Does not auto-publish by itself — pipeline continues only if Hands-off / scheduler would anyway.

Hands-off scheduling

Main Hands-off switch is in the top bar next to Restart API. Interval and queue depth live here.

Only applies while Hands-off is on. Then Studio checks about every 30 seconds and starts due queued topics into free pipeline slots (up to Max concurrent jobs). With Hands-off off, use Run now.

Hands-off generates topics when the queue is low (openai / LM Studio only), auto-schedules drafts, runs the pipeline, and uploads each job to YouTube as private without changing your default privacy. 0 hours = due now (FIFO).

Max concurrent jobs controls how many pipelines run at once (default 1). Raise when the server has more CPU/RAM (2, 4, 8…). Env BUBBLEPOD_MAX_CONCURRENT_JOBS / STICKMAN_MAX_CONCURRENT_JOBS overrides this field when set.

How HTTP /mcp authenticates (pick one): (1) Ngrok Basic only — username/password from Settings → Ngrok; do not also send Authorization: Bearer (many clients drop Basic when both are set). Stdio Claude/Codex does not need HTTP auth.
